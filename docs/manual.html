1소개 & 설치

Canvas Photo Editor는 브라우저 확장으로 설치해 새 탭에서 여는 사진 편집기입니다. 모든 처리는 로컬에서 이뤄지며 인터넷 연결이 필요 없습니다.

압축해제 로드로 설치

  1. 크롬 주소창에 chrome://extensions 입력 (엣지는 edge://extensions)
  2. 우측 상단 개발자 모드를 켭니다
  3. 압축해제된 확장 프로그램을 로드 버튼 클릭
  4. manifest.json이 있는 canvas-photo-editor 폴더 선택
  5. 툴바 퍼즐 아이콘에서 Canvas Photo Editor를 고정(pin) → 아이콘 클릭 시 새 탭에서 에디터가 열립니다
대상 OS: Windows 10/11 · 대상 브라우저: Chrome, Edge(Chromium). 코드를 수정한 뒤에는 확장 카드의 새로고침(↻)을 누르면 반영됩니다.

2화면 구성

실제 실행 화면입니다. 크게 ① 상단 메뉴바 · 옵션바, ② 좌측 도구상자, ③ 중앙 캔버스, ④ 우측 패널 묶음으로 구성됩니다.

① 상단 메뉴/옵션바

  • 파일·편집·이미지·레이어·선택·필터·보기 메뉴
  • 현재 도구의 세부 옵션이 옵션바에 표시
  • 좌측 ↶↷ 실행취소/다시실행 버튼

② 좌측 도구상자

  • 선택·페인팅·리터칭·벡터·내비게이션 도구
  • 하단 전경/배경 색상 스와치
  • 일부 도구는 슬롯 순환(클릭 반복)

③ 중앙 캔버스

  • 줌 5%~3200%, 스페이스 드래그로 팬
  • 눈금자/그리드/가이드 표시 가능
  • 마칭앤츠 선택 표시

④ 우측 패널

  • 레이어·색상·견본·스타일·작업내역·채널·패스·문자·셰이프·브러시·액션·프리셋·파일브라우저
  • 헤더 클릭=접기, 드래그=순서변경/플로팅(⑩ 참고)

3도구상자

좌측 도구상자의 도구들입니다. 괄호 안은 단축키이며, 같은 슬롯을 공유하는 도구는 단축키를 반복해 순환합니다.

이동·선택

  • V이동
  • M선택 윤곽(사각/타원/단일 행·열 — 옵션바)
  • L올가미
  • W자동 선택(매직완드, 허용오차)

페인팅

  • B브러시(팁 5종·경도·불투명도·동역학)
  • N연필
  • E지우개
  • G페인트 버킷 / 그라디언트(슬롯 순환)

리터칭·복원

  • S복제 도장(Clone, Alt+클릭 소스)
  • K복구 브러시(Healing)
  • C패치(Patch)
  • J히스토리 브러시 / F아트 히스토리
  • Y패턴 스탬프

보정 브러시

  • O닷지/번/스펀지(범위·노출)
  • R흐리게/선명/번짐(Smudge)

벡터·텍스트

  • P펜(베지어/자유곡선, 패스)
  • U도형(사각/타원/직선/다각형/둥근사각)
  • A셰이프 레이어(벡터 윤곽)
  • T텍스트(IME, 재편집 벡터 텍스트)

정보·내비게이션

  • I스포이드 → 색 샘플러 → 측정(슬롯 순환)
  • 노트(주석) — 툴바 버튼
  • H손(팬) / Z줌
  • Q퀵 마스크 모드

4레이어 우측 레이어 패널

레이어 1장은 분리된 캔버스이며, 위에서 아래로 합성됩니다.

기본 조작

  • 추가·표시/숨김·불투명도·순서 변경
  • 복제·아래로 병합·보이는 레이어 병합(Shift+Ctrl+E)·평탄화
  • 잠금(투명/이미지/위치)·칠 불투명도(Fill)

블렌드 모드

  • 총 22종(네이티브 16 + 커스텀 6)
  • dissolve·linear burn/dodge·vivid/linear/pin light

마스크

  • 레이어 마스크(그레이스케일, 브러시로 편집)
  • 클리핑 마스크(Ctrl+G)
  • 벡터 마스크(펜 패스 → 클립)

레이어 스타일 (10종)

  • Drop/Inner Shadow·Outer/Inner Glow
  • Bevel/Emboss·Satin·Stroke
  • Color/Gradient/Pattern Overlay
  • Styles 팔레트 프리셋 9종 일괄 적용

조정 레이어 (비파괴)

  • 밝기/대비·색조/채도·레벨·커브
  • 포스터화·한계값·반전·흑백
  • 아래 레이어 전체 보정, 마스크로 강도 조절

특수 레이어

  • 셰이프 레이어(채움+벡터 윤곽 재편집)
  • 벡터 텍스트(글꼴/자간/행간 재편집)

5색보정 & 필터 이미지 메뉴

색보정 (실시간 미리보기)

  • 레벨(채널 RGB/R/G/B/알파 + 히스토그램)
  • 커브(채널별 톤 곡선, Catmull-Rom)
  • 밝기/대비·색조/채도·색상 균형
  • 한계값·포스터화·그라디언트 맵·균일화·채널 혼합
  • 자동 레벨·흑백·색 반전

필터

  • 가우시안 블러(StackBlur)·모션 블러
  • 샤픈·언샤프 마스크·하이 패스
  • 노이즈·미디언·모자이크
  • 엣지 찾기·세피아·엠보스
  • 픽셀 유동화(Liquify) — 밀기/오목/볼록/소용돌이

이미지 모드

  • RGB ↔ 회색조(가중평균)
  • 인덱스 색상(median-cut + 디더)
  • 비트맵(1bit) · 색상표(Color Table)
  • 전 레이어를 단일 실행취소로 변환

채널

  • R/G/B/알파 채널 격리 보기
  • 채널 → 선택 영역 변환
  • 불투명(알파) 영역을 선택으로

6선택 & 변형 선택·편집 메뉴

선택 만들기

  • 사각/타원/단일 행·열, 올가미, 자동 선택
  • 색상 범위(스포이드+허용치)·확대(Grow)·유사(Similar)
  • 모두 선택 Ctrl+A · 해제 Ctrl+D

선택 다듬기

  • 반전 Shift+Ctrl+I · 페더 Alt+Ctrl+D
  • 확장/축소/테두리/둥글리기
  • 윤곽 그리기(Stroke, 폭·색·위치)
  • 선택 저장/불러오기 · 퀵 마스크 Q

변형

  • 이미지 크기 · 캔버스 크기
  • 90°/180° 회전 · 좌우/상하 뒤집기
  • 선택 영역으로 자르기
  • 자유 변형 Ctrl+T(Scale/Rotate/Skew/Distort/Perspective)

7벡터 · 텍스트 · 패스

펜 & 패스

  • 베지어 앵커/제어 핸들, 패스 닫기
  • 표준/자유곡선 모드, Alt+앵커=코너↔곡선 전환
  • Paths 팔레트: 선택 변환·채우기·획

텍스트

  • 클릭 입력(한글 IME), 재편집 가능한 벡터 텍스트
  • Character 팔레트: 글꼴·크기·색·자간·행간·굵게·기울임

셰이프

  • 사각/타원/다각형(3~12)/둥근 사각
  • 채우기·외곽선·선 두께, Shift로 정형

8자동화 & 파일

자동화

  • 액션(매크로): 작업 녹화·재생, 세트 관리
  • 패턴 메이커: 타일 패턴 생성·저장
  • 툴 프리셋: 도구 옵션 묶음 저장/적용

파일 입출력

  • 열기: 파일 선택 · 드래그앤드롭 · 클립보드 붙여넣기
  • 저장: PNG / JPG
  • Save for Web: 포맷·품질·미리보기·용량 추정

파일 브라우저

  • 연 이미지 썸네일 자동 저장(IndexedDB)
  • 최근 이미지 그리드(LRU 30개)
  • 클릭 재열기 · 세션 간 영속

9보기 & 내비게이션

줌 · 팬

  • 휠 줌 5%~3200%
  • 스페이스 드래그 또는 손 도구로 팬
  • 화면 맞춤 Ctrl+0 · 실제 크기 Ctrl+1

보조선

  • 눈금자 Ctrl+R
  • 그리드 · 가이드(추가/지우기)

10패널 도킹 · 플로팅 최신

우측 패널들을 자유롭게 재배치할 수 있습니다.

순서 변경

  • 패널 헤더를 같은 도크 안에서 위/아래로 드래그

플로팅 / 도크 이동

  • 헤더를 캔버스나 가장자리로 드래그 → 좌/우/하단 도크 이동 또는 자유 플로팅
  • 플로팅 패널의 ⤓ 버튼으로 도크 복귀

크기 · 접기 · 저장

  • 도크 경계 드래그로 너비/높이 조절
  • 헤더 클릭으로 접기/펴기
  • 모든 배치는 자동 저장(다음 실행에 복원)
