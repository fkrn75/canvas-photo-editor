## ✅ 수정 완료 (2026-06-15, 사용자 승인 후)
P1 전건을 수정하고 8124 런타임 재현으로 검증함(콘솔 에러 0, 패널 12 회귀 0):
- **#1 마스크 유실** — `document-command.js` `_capture/_restore`에 마스크 ImageData·조정/블렌드 메타 보관·복원. (검증: 마스크+회전→undo 후 마스크·그린 픽셀 보존)
- **#2 도구 전환 누수** — `tool-manager.js`가 전환 시 미완료 pixel-edit를 `cancelPixelEdit`로 정리(12개 도구 일괄) + `art-history-brush-tool.js` `onDeactivate`로 ctx 클립 복원. (검증: pe_cleared/down_cleared=true)
- **#3 tool-manager null 역참조** — 포인터 핸들러 `?.` 가드.
- **#4 dialogs keyHandler 누수** — `close()`에서 keydown 리스너 일괄 해제.
- **#5a 복제 메타** — `DuplicateLayerCommand`가 조정/셰이프/벡터텍스트 메타 승계. (검증: 조정레이어 복제 type=adjustment·params 보존·참조 격리)
- **#5b 조정 깊은복사** — `AdjustmentParamsCommand` JSON 깊은복사(중첩 객체/배열 격리).
- **#5d MergeDown 조정** — 조정 레이어 아래병합 시 `composeAdjustment`로 효과 굽힘. (검증: 회색 128→0)
- **#6 getDocks 충돌** — `.dock[data-dock]` 한정으로 스플리터 오인 차단. (검증: 3도크 dock-ok)
- **#5c toggleClip/toggleMask 메시지 — [정정] 실제 정상**(R3 오판). `LayerPropCommand`가 newVal을 직접 set하고 status는 그 후 값을 읽으므로 메시지가 올바름 → 수정 불필요.

> P2/P3는 미수정(후속 과제): 정밀도 `Math.round` 누락, blur radius 상한, IME isComposing, lasso/marquee 오버레이 잔상 등.

## 🔴 P1 — 기능 오작동 / 데이터 손실

### 히스토리·문서 (R2)
- **`history/commands/document-command.js:17` — 문서 변형 undo 시 레이어 마스크 유실** *(데이터 손실)*
  `_capture()`가 `l.snapshot()`(픽셀)만 보관하고 `l.mask`/`maskEnabled`/`maskActive`를 누락. 마스크를 단 레이어에서 이미지 크기변경·자르기·회전·뒤집기 → undo 시 마스크가 사라짐.
- **`history/command-manager.js:37` — `_bytes` 과계상.** `_push`에서 `redoStack.length=0`으로 폐기하면서 그 바이트를 `_bytes`에서 차감하지 않음 → 256MB 메모리 상한이 부정확하게 동작(undo→redo→새편집 반복 시 누적).

### 레이어 (R3)
- **`history/commands/layer-structure-command.js:38` — 셰이프/조정 레이어 복제 시 메타 누락.** `DuplicateLayerCommand`가 `vectorShape`/`type`/`adjustmentType`/`adjustmentParams`/`vectorMask`를 복사 안 함 → 셰이프=빈 픽셀 레이어, 조정=합성에서 무시됨.
- **`history/commands/adjustment-command.js:30` — 조정 파라미터 얕은복사 오염.** `{...before}`는 1-depth라 레벨(`rgb/r/g/b` 중첩)·커브(`[{x,y}]` 배열)가 외부와 참조 공유 → undo 후 재편집 시 이전 값까지 변함. `cloneParams()` 필요.
- **`history/commands/layer-structure-command.js:84` — MergeDownCommand가 조정 레이어를 굽히지 못함.** 조정 레이어를 아래로 병합하면 빈 투명 캔버스를 normal 합성 → 보정 효과 소실.
- ~~**`layers/layer-manager.js:207,189` — toggleClip/toggleMaskEnabled 상태 메시지 반전.**~~ **[정정: 오판, 실제 정상]** `LayerPropCommand`는 `newVal`을 직접 set하고 status는 그 후 값을 읽으므로 메시지가 올바르다. 수정 불필요.

### 도구 (R5) — 시스템적 패턴
- **드래그 중 도구 전환 시 `onDeactivate` 미구현 → `beginPixelEdit` 누수·undo 오염** *(다수 도구 공통)*
  `tool-manager.js:96 setTool`이 `onDeactivate?.()`를 부르지만 paint/clone-stamp/healing/history-brush/dodge-burn/blur-smudge/pattern-stamp/gradient/move/marquee/lasso/art-history 가 미구현. 드래그(버튼 누른 상태)에서 단축키로 전환하면 열린 pixel-edit 세션이 commit/cancel 없이 방치 → 다음 편집이 `_peBefore`를 덮어써 undo가 깨지거나 미리보기가 확정됨. **아트 히스토리는 `ctx.save()`가 restore 안 되어 클립 상태까지 잔류.**
- **`tools/tool-manager.js:135,147,158` — 초기화 타이밍 null 역참조 크래시.** `this.active=null` 상태(첫 `setTool` 이전)에서 포인터 이벤트가 오면 `this.active.onPointerDown(...)`에서 TypeError. down/move/up에 `?.` 누락(leave만 있음).

### UI (R6)
- **`ui/dialogs.js:27` — OK 버튼 클릭 시 `keyHandler` window 리스너 미해제.** Escape/Enter 경로에서만 `removeEventListener` → 마우스로 확인 클릭 시 핸들러 잔류. 다중 모달에서 Enter 1회로 이중 실행, `onOk` 재호출(이중 저장/다운로드) 위험.
- **② `ui/panel-dock.js:43` + `panel-splitter.js:66` — `data-dock` 속성 충돌.** 스플리터 핸들에도 `dataset.dock`이 붙어 `.main` 안에 `[data-dock="right"]`가 도크와 스플리터 2개 존재. `getDocks`가 클래스 아닌 속성 셀렉터로 탐색 → **현재는 DOM 순서상 우연히 정상**이나 `initPanelDock` 재호출/재배치 시 스플리터를 도크로 오인. 권고: `.dock[data-dock="..."]` 또는 핸들에 다른 속성명. *(지휘자 런타임 확인: querySelector는 현재 정상 도크 반환)*

## 🟠 P2 — 경미 / 엣지케이스

- **정밀도 — `Math.round` 누락(R1).** `filters.js`(convolve3/unsharpMask/sepia), `adjustments.js`(hueSaturation/equalize/channelMixer), `blend.js`(buildEffectiveSource:201/clipAlphaByAlpha:224)에서 float를 Uint8ClampedArray에 직접 대입 → 반올림 아닌 내림(floor)으로 최대 1단계 색오차·밴딩. 크래시 아님.
- **`engine/blur.js:51` — stackBlur radius≥255 시 MUL/SHG 배열 초과 → NaN → 화면 전체 검정.** UI 슬라이더 상한이 255 미만이면 미발생(상한 확인 필요). *(의심)*
- **`engine/adjustments.js:121` — buildCurveLUT n=0/1 입력 시 TypeError.** 정상 흐름은 `curveIsIdentity`(p.length===2) 가드로 보호되나 파라미터 임포트/마이그레이션 경로는 unchecked.
- **`text/text-tool-v.js:126` — 텍스트 편집 중 IME `isComposing` 미체크.** 한글 조합 중 Character 팔레트 변경 시 `el.style.font` 교체로 IME 세션이 끊겨 자모 분리 확정.
- **`filters/liquify.js:84` — FORWARD 모드 변위에 strength 이중 적용.** 다른 모드(pucker/bloat/twirl)와 강도 일관성 없음. *(의심: 의도일 수 있음)*
- **`selection/selection-manager.js:380` — Stroke center 홀수폭 1px 비대칭** / **`:668` similar tolerance=0 양자화 누락.**
- **`transform/free-transform.js:510` — Shift+Scale 시 `oh===0` 나누기 0** / **`:423` `_pointInQuad` 퇴화 사각형 true 반환.**
- **`tools/blur-sharpen-smudge-tool.js:192` — Smudge 캔버스 경계서 픽업 버퍼 한 스텝 끊김.**
- **`tools/shape-tool.js:140` — 채우기·테두리 모두 OFF면 빈 undo 스텝 생성.**
- **`engine/brush-dynamics.js:101` — scatterCount 상한 미검증**(후속 clamp는 있음).
- **`actions/actions-manager.js:86` — `img.rotate180`이 `rotate90` 2회 → undo 2단계.**
- **② `ui/panel-collapse.js:45` — `.opt-toggle` 예외 누락**(panel-dock/float와 불일치).
